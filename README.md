# AUVR Anti-Kick

Stops you from being kicked from lobbies. Meant to protect you from exploiters kicking you out of lobbies, but it overall stops you from being vote kicked, unless the host uses the ```NetworkRunner.Disconnect(PlayerRef)``` function, which is server-side/host-side, so you can't prevent this. But, if an exploiter is the host, I think they would have already crashed your game.

I have no doubt that this will be used by exploiters.

Just don't think you're god.
